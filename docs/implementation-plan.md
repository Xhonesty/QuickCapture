# 0.6 实施记录

用户已确认五个模块及推荐交互。仅在 QuickCapture 内操作。

1. 统一设计变量，颜色不变；Lucide 图标与配置驱动快捷键。
2. 原图坐标标注 + 可撤销裁剪范围，八手柄、整体移动、1/10 物理像素微调。
3. PNG/JPG/WebP/BMP 保存窗，独立截图默认格式/质量；编码数据及标准位图剪贴板。
4. 原生 MP4 母版；停止打开编辑/导出窗。FFmpeg/ffprobe 系统优先、捆绑备用、缺失降级。
5. MP4/WebM/GIF；时间轴起止（P0）、变速（P1）、静音；GIF 15 FPS 默认，提取音频/MKV/MOV 后续。
6. 取消/失败保留 Data/Recordings 中的母版，成功导出后清理该母版；退出仅完成录制，不弹编辑窗。
7. 分阶段验证、24 项回归、新增像素/格式/音画同步/取消/降级检查；双主题视觉检查；文档、打包、GitHub 同步。

默认：PNG，JPG/WebP 90；MP4 中质量；GIF 15 FPS。保存弹窗，复制及自动保存不弹窗。

## 自查与完成情况

0.5.0 的框选在松开鼠标后立即进入标注；原位和独立编辑器均没有八向手柄、整体选区移动或再次裁剪。0.6.0 已统一实现可撤销的裁剪视口，所有标注保存在原图坐标中，范围外只隐藏。

工具按钮、tooltip、快捷键、启用状态、分组与悬停菜单均由 `ToolCatalog.cs` 声明；扩展字段 `Children` 预留二级工具结构。图标为固定提交的 Lucide SVG。

五个模块按确认范围实现；P0 裁切长度和 P1 变速均完成，P2 GIF / 静音完成。提取音频和 MKV / MOV 留待后续。样式规范及媒体依赖文档分别见 `design-spec.md` 和 `media-tools.md`。各阶段检查与复现命令见 `verification.md`。

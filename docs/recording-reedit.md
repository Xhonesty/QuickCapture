# 一屏录屏编辑与再次编辑

2026-10-07：主界面顶部“编辑录屏”按钮已移除，继续编辑通过最近文件菜单和录屏停止后流程进入；以下编辑器行为沿用。

录屏编辑器默认 880×820 DIP，预览区随窗口高度伸缩，下面的导出选项和保存位置并排。内容区不使用整页滚动；较矮窗口将格式说明收进导出选项的提示，所有输入和裁剪操作保持显示。“选择文件夹”在目录输入框右侧。视频加载完成前的时间轴跳转会保留，并在打开画面后应用。

从最近文件的“更多 → 编辑录屏”打开已经保存的 MP4、WebM 或 GIF。双击普通文件仍使用系统播放器，待导出母版仍沿用原来的继续编辑行为。

再次编辑默认使用源目录和“原文件名-编辑”文件名；已有同名副本时自动增加序号。可截取时间、裁剪画面、修改倍率、声音、质量、帧率和导出格式。导出副本加入最近文件，支持继续打开编辑。取消保留原文件，不为外部录屏写入母版配置；禁止覆盖正在编辑的源文件。损坏文件会显示错误并阻止导出。

WebM / GIF 以及 Windows 播放器不兼容的编码会准备 H.264 / AAC 预览副本。预览可能降至 1280 像素宽；裁剪坐标和导出仍使用原始视频。准备过程可以关闭窗口取消。临时副本位于本程序 Data/RecordingPreviews，关闭编辑器后删除。

验收命令：

```powershell
.\dist\QuickCapture.exe --self-test --recording-edit-only
.\dist\QuickCapture.exe --self-test --editor-ui-only
```

专项覆盖两种主题、880×820 与 680×600 窗口、展开裁剪且无控件截断；实际 WPF 视频渲染的红 / 绿 / 蓝帧对应时间轴起点 / 终点；通过真实最近文件菜单重新打开三种格式、裁剪和截取后导出、再次取消，以及源 SHA-256 和预览清理。拖动事件通过 WPF 路由事件触发；原生物理指针和混合 DPI 多屏仍需另行实测。

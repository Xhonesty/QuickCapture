## 修复与验证方式

集中检查覆盖标注渲染、编辑器与工具菜单，原生 ScreenRecorderLib 采集／编码，WASAPI 音频，主界面／托盘，FFmpeg 时间编辑／导出及 Win32 窗口枚举。开发后执行一轮完整检查；受限进程首次出现桌面与音频访问拒绝，相关项转入正常桌面会话定向验证。

失败项修复包括调色图标的 WPF 父级冲突、悬停菜单焦点收起、屏幕吸管在边缘采到自身预览、原生暂停边界保留旧帧、窗口测试夹具显示及旧 WGC 截图初始黑帧。最后发现库会丢弃静态窗口首帧，已改为等待真实 producer 帧，并仅在等待期间有限次异步请求该窗口重绘；不依据黑色像素判定有效性、不改窗口位置／尺寸／焦点。原有窗口截图测试已加强像素断言。

追加只读审查发现的对象键盘越界、录屏准备阶段停止及裁剪成功删除母版问题均已修复；只补查受影响的对象、控制状态、裁剪配置和采集路径。功能通过后停止测试。

## 关键模块

- `AnnotationSurface.cs`、`ScreenshotEditor.cs`、`ColorPalette.cs`、`PixelEyedropper.cs`：对象模型、绘制、统一历史、颜色与独占取色。
- `RecorderService.cs`、`RecordingBar.cs`、`MainWindow.xaml.cs`、`Native.cs`：原生暂停、状态／计时、控制条位置和排除、托盘及可靠首次帧截图。
- `RecordingEditWindow.cs`、`VideoCrop.cs`、`VideoCropOverlay.cs`、`VideoExportService.cs`、`RecordingRecovery.cs`：裁剪交互、源坐标、FFmpeg、母版／配置恢复。
- `WindowPicker.cs`、`SelectionWindow.cs`：实时窗口缩略图、目标高亮与区域吸附辅助预览。
- `MainWindow.xaml`、`ToolCatalog.cs`、`HoverToolOptions.cs`：紧凑默认窗口、形状入口与菜单。
- 复用 `SelfTest.cs` 及原检查，增加四个功能检查模块；支持保留已通过结果的 `--failed-only` 与按名称 `--recheck=`。

## 平台与验证边界

- Windows 10 2004 及以上支持控制条捕获排除。本机已实际验证；较旧系统使用选区外／其他显示器或隐藏控制条的降级，仍可用托盘和停止快捷键。旧系统降级未实机运行。
- 受保护窗口不能绕过捕获限制；无法读取屏幕像素时明确提示，画布吸管仍可用。
- 空间裁剪需 FFmpeg／ffprobe，发布目录包含固定备用工具；缺工具时保留完整 MP4 保存路径。
- 实测仅单屏 125% 和短时录制。负原点、150%／200% 属几何检查；真实混合 DPI 多屏、数小时同步、设备热插拔、其他 Windows 版本未实机验证。
- 成功裁剪保留的完整母版占用额外磁盘空间。未裁剪成功导出沿用原清理流程。

## 复现

在允许桌面采集与默认麦克风访问的普通交互桌面中运行：

```powershell
.\tools\build.ps1 -Offline -Test -Microphone
# 仅失败项，保留已通过结果：
.\dist\QuickCapture.exe --self-test --failed-only --audio --microphone
# 例如仅复测失败的窗口模块：
.\dist\QuickCapture.exe --self-test --failed-only --shell-only
# 显式补查受到核心修改影响的路径：
.\dist\QuickCapture.exe --self-test --failed-only "--recheck=Windows Graphics Capture window screenshot"
```

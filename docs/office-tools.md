# 办公文字、步骤编号与贴图 · v0.8.0

主窗口保持原有布局。新入口位于共享截图工具栏、OCR 结果窗口、贴图右键菜单和托盘；区域原位截图、窗口截图和整桌面编辑器使用同一套实现。

## 提取文字

截图后点击“提取文字”或按 `O`。本地 Tesseract 5.2.0 对点击时当前裁剪范围的原图进行识别，标注和马赛克不会进入识别输入。支持“简体中文 + English”“繁體中文 + English”“English”。输入与结果只进入程序 `Data/OcrJobs` 中本次任务的独立目录，完成、失败、取消后删除；无网络识别调用。

结果窗口可调整大小、输入中文英文、修改识别错误、一键复制。默认保留换行，勾选“复制时合并换行”可获得单段文本；该选项只影响复制，保留可编辑原文。合并时保留英文词间空格，连续中文换行直接衔接。语言及复制模式自动保存。

识别中、识别完成、无文字、组件缺失、失败、取消分别显示状态。面板非模态，截图仍可编辑；“重新识别当前范围”会读取最新裁剪范围。关闭面板或截图编辑器会取消任务，等待私有工作进程退出，再删除临时文件。单次任务最多 90 秒，超时可缩小范围重试。复制剪贴板被占用时短暂重试。

标注画布显式禁用输入法以保证 `D` / `E` / `O` 工具快捷键；原位文字和 OCR 结果输入框仍可使用中文输入法。图像复制统一提供所选编码、Windows 标准位图和原生 DIB，支持退出程序后继续粘贴。

缺语言组件时重新完整解压便携包；从源码构建运行 `python tools/setup-ocr.py`。不依赖 Windows OCR 语言包，无需 GPU。手写、倾斜、低分辨率、复杂排版和深色小字可能误识别；需自行核对重要文字。翻译、表格结构及公式识别见后续路线图。

## 步骤编号

点击“步骤编号”或按 `D`，连续单击画面添加 1、2、3。工具面板调整直径、下一个编号；“设置起始数字”只影响后续新增，不修改已有对象。起始值和默认直径保存至设置。每次新截图从保存的起始值开始，本次截图内的计数持续递增，删除或撤销不回收编号。范围为 1–9999，达到上限后提示重置。

按 `E` 选中编号，拖动移动、拖动手柄缩放、方向键微调、`Delete` 删除。双击编号打开选项，可修改选中数字；调色盘和吸管可调整颜色。修改数字、尺寸、颜色、移动、删除均接入原有 `Ctrl+Z` / `Ctrl+Y` 撤销重做。编号保持圆形，长数字自动缩小；实色填充、黑白双边框及对比数字保证背景可读性。

编号始终保存原图像素坐标，二次裁剪不移动或删除原对象。缩放和滚动只影响预览，复制、保存和贴图输出保持裁剪后的原始像素尺寸。

## 贴图

工具栏“贴图”或 `P` 将当前裁剪和标注结果置顶。左键拖动移动，滚轮围绕鼠标位置等比例缩放，`Ctrl+滚轮` 按 5% 调整透明度（20%–100%）。右键菜单提供复制、保存、恢复原尺寸、透明度、鼠标穿透、隐藏全部和关闭；`Ctrl+0` 恢复原尺寸，`Esc` 关闭当前贴图。复制和保存使用完整原图，不受显示缩放或透明度影响。

恢复原尺寸指 1 原图像素对应 1 屏幕物理像素；大图超过当前显示器工作区时自动适应屏幕。缩放限制为 5%–800%，上限同时受当前屏幕大小限制。拖动结束后回到最近显示器工作区内，支持负坐标及 DPI 切换；显示器配置改变时重新约束位置。

开启穿透后贴图不接收点击。右键穿透入口明确提示恢复方式：系统托盘 → **解除全部贴图穿透并恢复**。这是始终可用的恢复入口，不占用新的全局快捷键。托盘还提供隐藏全部、恢复全部、关闭全部。隐藏保留每张图的缩放、透明度和穿透状态；恢复保持当前状态，解除穿透入口同时恢复可见性。新贴图会恢复当前隐藏集合。

默认透明度持久化。穿透、隐藏、缩放、图片和位置属于本次会话，不跨重启恢复，避免意外产生无法点击的浮窗。退出软件关闭全部贴图。

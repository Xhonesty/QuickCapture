轻截 v0.11.0 更新设置布局、可继续编辑的截图与录屏，以及声音设备选择。

- **三个设置标签**：通用与媒体工具、截屏、录屏。默认 480×680 DIP 下全部设置可见，无需滚动；顶部标签和底部按钮固定。支持键盘切换、跨页保留输入、统一保存及取消恢复，沿用主题预览、快捷键录入和各格式独立帧率。声音检测与试录使用二级页面，设置草稿不会提前写入。
- **主界面与马赛克**：移除顶部图片编辑和录屏编辑按钮，主题、设置及窗口控制合并为一行。最近文件的继续编辑入口和录屏停止后的编辑保留。马赛克使用确认后的九格像素 SVG，适配两种主题、选中、禁用及高 DPI。
- **声音设备**：分别选择麦克风输入与系统声音播放设备，支持跟随默认、刷新、电平检测、三秒试录及回放。缺失设备保留选择，设备中断时停止并保留已录原片；控制条显示真实电平。
- **多段录屏剪辑**：支持删除中间片段、合并重叠范围、调整或恢复片段、撤销重做与自动跳过预览，可组合首尾裁切、画面裁剪、变速和静音，再导出 MP4 / WebM / GIF。
- **截图项目与再次编辑**：保存图片时保留原图、标注、文字样式、编号和裁剪状态。最近文件可恢复对象继续修改；保存更新当前版本，另存为创建独立版本。录屏编辑器一屏显示主要控件，预览跳转同步时间轴；再次编辑默认另存副本，保留原文件。

验证：Windows x64 自包含 Release 构建成功。设置/主界面 13 项、正式图标/编辑入口 3 项定向检查通过；声音设备、多段剪辑与截图项目另有较早的 26 项阶段验收记录。按修改影响执行检查，失败修复后定向复测，未受影响的结果沿用；这些数字不代表最终构建后重复执行全部历史套件。检查覆盖真实 WPF 布局、路由交互、生成的媒体与项目恢复。单屏 125% DPI；混合 DPI 多屏、完整原生键鼠与长时间音频录制未做本轮专项复测。

下载 `QuickCapture-win-x64.zip`，解压完整文件夹后运行 `QuickCapture/QuickCapture.exe`。包含 .NET x64 运行时、FFmpeg / ffprobe、本地 OCR 模型及许可文件，无需安装 SDK。保持 Microsoft Visual C++ x64 运行库要求。SHA-256 校验文件随 Release 提供。

升级前备份原程序目录的 `Data` 和捕获文件；使用新包时复制所需配置与项目，保存目录仍可在设置中调整。普通图片、视频与旧帧率配置继续兼容。项目关联使用本地绝对路径，手动移动导出文件后需恢复路径或使用应用另存为建立新关联。

轻截 v0.8.0 加入本地 OCR、步骤编号和贴图增强，适合日常办公、操作说明与资料对照。主面板保持原有布局，新功能位于截图工具栏、结果面板和贴图菜单。

- **提取文字 `O`**：本地识别当前裁剪范围的简体中文、繁体中文和英文；可编辑结果、一键复制、保留 / 合并换行。识别不阻塞截图编辑，关闭面板或编辑器会取消私有工作进程并清理临时文件，语言缺失、无文字、失败和取消均有明确状态。完整便携包包含三个固定 SHA-256 模型。
- **步骤编号 `D`**：单击连续生成编号；`E` 选中后可移动、缩放、删除，双击修改数字，调整颜色和尺寸；支持撤销重做。删除不重排，选项面板可以重设下一个数字。原图坐标保证裁剪和缩放导出一致。
- **贴图 `P`**：滚轮等比例缩放、`Ctrl+滚轮` 透明度、`Ctrl+0` 恢复原尺寸；右键复制、保存、透明度、穿透和关闭。托盘提供统一隐藏、恢复、关闭，以及 **解除全部贴图穿透并恢复**。支持负坐标和按物理像素放置，大图自动适应工作区。
- 持久化新增偏好并兼容旧配置；修复中文输入法吞掉画布工具快捷键，中文文字输入继续可用；修复 BMP 重复读取兼容性，图像复制统一提供所选编码、原生位图及 DIB。复用现有保存、标注、主题及错误机制。
- 更新 README、简明使用说明、OCR 方案 / 许可证 / 包体比较和后续路线图。路线图包含长截图、音频设备与电平、录屏点击与组合键提示、中间片段删除、可编辑截图保存、历史检索，以及各项依赖和相对投入。

Windows x64 便携包包含 .NET、FFmpeg / ffprobe、OCR 原生库及语言模型；解压完整文件夹后运行 `QuickCapture/QuickCapture.exe`。随附 SHA-256 校验文件；不能只复制 EXE。

验证：办公专项 9 项，既有截图编辑与格式 9 项，原位文字 / 最近文件 8 项，设置 / 帧率 11 项，媒体导出 10 项，视频裁剪 / 恢复 3 项，窗口 / 采集 2 项，真实录屏暂停 / 混音 2 项通过。办公专项包含实际鼠标、滚轮、快捷键、剪贴板、OCR 子进程取消和两主题界面。生成的清晰印刷简体、繁体及英文样本字符误差为 0（去除空白后的指标），不是所有资料的准确率保证。

本机为单屏 125% DPI；真实混合 DPI 多屏、设备热插拔、复杂版面 / 手写 OCR 和人工验收尚未验证。贴图集合不跨重启恢复；超过屏幕的大图恢复尺寸时适应工作区。翻译、表格及公式识别列入后续计划。完整边界见包内 `docs/verification.md`。

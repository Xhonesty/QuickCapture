# 两层截图工具栏与最近文件预览 · v0.9.0

区域截图与窗口 / 桌面截图编辑器共用 `ScreenshotToolbar` 和 `ScreenshotEditor`。主栏按绘制、编辑、输出分组，使用 32 DIP 按钮、20 DIP 线性图标、细分隔线及 11 DIP 圆角。带属性的绘制工具显示小箭头；悬停提示包含工具名称及原快捷键。浅色面板使用白色，选中状态使用蓝色；深色保持相同层级，悬停、按下、选中及禁用有独立状态。

属性面板与主栏相隔 8 DIP。形状、箭头、文字、步骤编号、涂鸦和马赛克各有自己的属性行；选择已有标注时显示该对象的设置。其他属性行隐藏但保留测量尺寸，所以切换工具、修改数值或开始 / 完成文字不会使面板跳动。屏幕或编辑器变窄时自动换行，按钮保持原有尺寸。区域截图仍优先将两栏一起放在选区下方，空间不足时避让到上方或侧面；全屏选区放在可操作的工作区内。界面不会进入导出图片。

常用颜色直接点击色块，当前预设颜色用描边标识，自定义颜色显示在调色盘图标的小色条中。`K` 或调色盘按钮保留 HSV、HEX、透明度、最近颜色及填充颜色设置；属性栏吸管按钮直接采样画布，调色盘内保留屏幕吸管。文字仍支持原位中文 / 英文、多行输入、字体、字号、粗体与对齐。文字属性旁显示“完成文字”和“取消文字”；`Ctrl+Enter` / `Esc` 保持原行为。

最近文件行继续使用 48 DIP 行高、32×32 DIP 左侧区域和原文字 / 操作对齐。PNG、JPG、WebP、BMP 等显示真实内容并等比例留白；透明图片用棋盘格显示透明区域。视频使用现有 FFmpeg 读取首帧，带播放标记；GIF 显示第一帧。加载、文件缺失、格式损坏或 FFmpeg 不可用时显示对应类型图标，悬停可查看状态。双击、Enter、更多菜单、打开目录和移到回收站保持原行为，“待导出”母版仍可继续编辑。

文件元数据、解码和视频进程都在后台运行，同时最多两项。图片按当前 DPI 所需的预览像素解码，最长边限制在 32–256 px；WPF 原生格式使用缩小解码，WebP 使用 Skia 的目标尺寸解码。视频进程限时 8 秒，取消加载时终止进程。内存缓存最多 96 项，按最近使用顺序淘汰，以完整路径、长度、修改时间及预览像素尺寸标识文件。刷新会更新文件版本；控件卸载、绑定变化和 DPI 变化会取消旧加载，只有当前请求可显示结果。列表容器启用回收式虚拟化。

在 QuickCapture 目录构建与验收：

```powershell
.\tools\build.ps1 -Offline
.\dist\QuickCapture.exe --self-test --toolbar-only
```

该专项使用生成的图片与视频，实际显示 WPF 窗口并操作测试文件的打开 / 回收站与继续编辑入口。结果在 `dist/Diagnostics/results.json`，截图在 `artifacts/screenshots/`。运行需要普通交互桌面权限；真实系统输入法候选窗与混合 DPI 多显示器仍需在对应环境验收。具体结果见 [验收记录](verification.md)。

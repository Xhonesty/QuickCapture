# 录屏编辑主题与按需截图属性栏 · v0.10.0

## 录屏编辑

`RecordingEditorStyles.xaml` 为录屏窗口提供局部样式，颜色统一由 `ThemeService` 管理。次要操作使用实色灰绿背景与可见边框；确认裁剪和导出使用青绿主色。悬停、按下、播放 / 已应用裁剪的选中状态、外圈键盘焦点与禁用各有独立样式，禁用控件保持实色和可读文字。原有媒体工具、格式及裁剪条件继续决定启用状态；编码期间冻结时间与输出选项，保留取消导出入口。

页面、卡片、标题、说明、文本框、下拉框与弹出列表、复选框、滚动条、时间轴、底部操作区、进度和导出错误均使用动态主题资源。切换应用主题立即更新已打开窗口。视频画面仍为黑色底，裁剪边界叠加黑 / 白轮廓与亮青绿描边，手柄与尺寸标签在明暗视频上均保持可见。导出错误直接显示在有主题的底部状态区，并写入原有错误日志。

`RecordingWindowChrome` 让标题栏左侧留空，保留内容区标题。右侧按钮调用 Windows 最小化、最大化 / 还原与关闭命令；32 DIP 原生标题命中区域与 6 DIP 调整尺寸边缘保留拖动、双击与窗口大小调整。初始高度适应工作区，最大化不再受初始窗口高度限制。

导出滤镜在变速与帧率处理后再限制目标时长，兼容本机 PATH 中 FFmpeg 4.2.3 与捆绑版本。旧版 `fps` 滤镜可能把已截取片段的最后一帧重复至原始终点时间；新的时长限制去除多余尾帧，同时保留声音同步。

## 截图属性栏

`ScreenshotToolbar` 保留同一组控件实例，使用 `Collapsed` 排除其他工具的属性测量。当前可见属性行按自然宽度加统一内边距和控件间距排布；宽度仅受可用工作区约束，窄屏用现有 `WrapPanel` 换行，并选择仍能容纳相同行数的最小内容宽度，避免最后一行只有一个按钮而留下大段空白。文字输入期间增加完成 / 取消控件，结束输入后收起并重新测量。主栏与属性栏各自按内容宽度显示，第二层不再固定长度。

裁剪与未选中对象的选择工具不创建属性行。复制、保存、取消、贴图及提取文字收起第二层；取消保存对话框后仍保持收起，重新选择绘制工具可恢复。选择带属性的已有对象时显示该对象选项，取消选择后清除。区域编辑器使用尺寸变化回调重新测量和屏幕避让，主栏与属性栏始终一起定位。

布局调整不重建文字编辑器或属性控件，也不修改快捷键、输入法、标注坐标及历史逻辑。中文 / 英文多行草稿、字体与颜色即时更新、组合中 Esc 保护、已存在对象取消恢复及单步撤销 / 重做都有事件级回归。

## 复现验证

在项目目录构建后运行以下专项；每次执行会更新 `dist/Diagnostics/results.json`，请分别保存。图件在 `artifacts/screenshots/`。

```powershell
.\tools\build.ps1 -Offline
.\dist\QuickCapture.exe --self-test --editor-ui-only
.\dist\QuickCapture.exe --self-test --context-toolbar-only
.\dist\QuickCapture.exe --self-test --media-only
```

`--editor-ui-only --pointer` 额外检查真实鼠标按下、窗口拖动和边缘缩放；`--toolbar-only` 含完整原位文字 / 快捷键 / 剪贴板回归，`--crop-only` 含实际视频手柄与 Esc。需要可以取得前台的交互桌面。默认录屏主题专项通过测试中的 WPF 只读状态键模拟悬停 / 按下，用真实窗口渲染检查状态区别，不代表物理指针投递已验证；标题栏测试向自身 HWND 查询真实命中结果，并执行实际窗口控制命令。

本轮前台窗口检查拒绝了真实键鼠注入，相关输入用例没有计入通过。系统中文输入法候选窗、混合 DPI 多屏移动、显示器拔插、其他 Windows 版本及重新采集系统声 / 麦克风仍需在对应环境复测。详细通过项、失败记录和发布包校验见 [验收记录](verification.md)。

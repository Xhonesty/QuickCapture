# 截图与录屏界面优化 · 2026-10-05

依据提供的界面修改说明、主面板定稿 HTML 和设置页定稿 HTML，在现有 WPF 软件中实现。本次改动包含主面板、设置页及共享主题资源；截图、录屏、编辑和导出的既有流程继续沿用。2026-10-06 按后续要求将设置窗口改为与主窗口同尺寸、仅保留“设置”标题，并实现按格式保存及同步帧率，最新行为和验收见 [帧率同步说明](recording-preferences.md)。

## 布局与样式

- 主面板默认 480×680 DIP；设置页打开时取主窗口当前宽高，标题仅为“设置”。2026-10-07 已改为三个无滚动分类标签，底部按钮固定，见 [最新设置分类](settings-categories-and-mosaic.md)。
- 页面圆角 14 DIP、卡片圆角 10 DIP、卡片内边距 14×12 DIP、卡间距 10 DIP，描边 0.5 DIP。
- 两个主按钮均为实心青绿，默认高度 36 DIP；录屏右列的重复区域和帧率控件均宽 122 DIP。
- 主面板使用统一线性图标、快捷键 chip、14×14 DIP 自定义复选框。没有上次区域时，重复按钮使用灰字与弱描边禁用态。
- 最近文件每行 48 DIP，按当前 DPI 取完整行，最多展示五行；文件名和路径支持省略号及完整内容提示。文件行悬停或键盘聚焦显示更多操作、打开目录，菜单提供打开文件、打开所在目录、移到回收站。回收站操作也保留待导出录屏的元数据，便于恢复。
- 录制中显示停止录制、红色状态点和时长；暂停时使用暂停后的计时值；空闲按钮不显示录制圆点。
- 设置单字段使用左置标签，多字段使用上置小标签。质量值在独立数值框显示；复选框说明单独缩进；卡片底部统一提示。
- 主面板和设置页的组件模板只使用动态颜色资源，表面不透明，无渐变、辉光、模糊或控件阴影。

## 主题实现与对比度

`ThemeService` 集中维护说明中的亮 / 暗 Token 并发送主题变化通知。WPF 使用 `DynamicResource`，相当于 HTML 根主题类切换；已有窗口同步更新，无需重建。`PanelStyles.xaml` 共享两页控件的默认、悬停、按下、禁用及键盘焦点样式。

主面板主题按钮立即保存。设置下拉立即预览，保存时提交；取消、Esc 或关闭设置恢复进入设置时的主题，其他字段也不提前写入磁盘。

说明中的部分 Token 组合不能达到要求的 4.5:1：亮色 `#6B7A77` 在页面背景上约 4.17:1、在卡片上约 4.49:1；白字在 `#1D9E75` hover 背景上约 3.39:1。保留原调色板，11px 信息文字使用已有 `#5C6B67`，亮色主按钮 hover 文字使用已有 `#141B19`，该状态约 5.16:1。暗色删除红在卡片上约 3.89:1，因此删除入口保留红色垃圾桶图标，暗色标签使用已有辅助文字色；亮色标签仍使用危险红。专项检查覆盖两主题的提示文字、快捷键 chip、删除菜单文字，以及主按钮默认、hover、pressed 文字对比度。

新配置采用 Ctrl+Alt+F8 / Ctrl+Alt+F9，已有设置中的快捷键保留。设置录入、快捷键冲突回滚和保存校验继续使用既有逻辑。
